### 문제 설명

<p>Given a set of sticks of various lengths, is it possible to join them end-to-end to form a square?</p>

### 입력 

 <p>The first line of input contains N, the number of test cases. Each test case begins with an integer 4 <= M <= 20, the number of sticks. M integers follow; each gives the length of a stick - an integer between 1 and 10,000</p>

<p> </p>

### 출력 

 <p>For each case, output a line containing "yes" if is is possible to form a square; otherwise output "no"</p>
