### 문제 설명

<p>The Fibonacci number ƒ<sub>K</sub> is defined by ƒ<sub>K</sub> = ƒ<sub>K-1</sub> + ƒ<sub>K-2</sub> with seed values ƒ<sub>0</sub> = 0, ƒ<sub>1</sub> = 1. It is known that every positive integer can be represented as the sum of one or more distinct Fibonacci numbers. There are many different representations of Fibonacci sums for a positive integer. For example, Fibonacci sums for 100 can be represented by ƒ<sub>4</sub> + ƒ<sub>6</sub> + ƒ<sub>11</sub> = 3 + 8 + 89 or ƒ<sub>1</sub> + ƒ<sub>3</sub> + ƒ<sub>6</sub> + ƒ<sub>11</sub> = 1 + 2 + 8 + 89, or ƒ<sub>4</sub> + ƒ<sub>6</sub> + ƒ<sub>9</sub> + ƒ<sub>10</sub> = 3 + 8 + 34 + 55 etc. In this problem, we want to find the minimum number of Fibonacci numbers for an integer.</p>

<p>For a given positive integer, find the minimum number of distinct Fibonacci numbers whose sum is equal to the given number. </p>

### 입력 

 <p>Your program is to read from standard input. The input consists of T test cases. The number of test cases T is given in the first line of the input. Each test case contains one positive integer n , where 1 ≤ n ≤ 1,000,000,000. </p>

### 출력 

 <p>Your program is to write to standard output. Print exactly one line for each test case. The line should contain the Fibonacci numbers in increasing order which sum is equal to the given number. </p>
