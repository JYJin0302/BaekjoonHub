### 문제 설명

<p>“Peter Pan frames” are a way of decorating text in which every character is framed by a diamondshaped frame, with frames of neigbhouring characters interleaving. A Peter Pan frame for one letter looks like this ('X' is the letter we are framing): </p>

<pre>..#..
.#.#.
#.X.#
.#.#.
..#..</pre>

<p>However, such a framing would be somewhat dull so we'll frame every third letter using a “Wendy frame”. A Wendy frame looks like this: </p>

<pre>..*..
.*.*.
*.X.*
.*.*.
..*..</pre>

<p>When a Wendy frame interleaves with a Peter Pan frame, the Wendy frame (being much nicer) is put on top. For an example of the interleaving check the sample cases.</p>

### 입력 

 <p>The first and only line of input will contain at most 15 capital letters of the English alphabet. </p>

<p> </p>

### 출력 

 <p>Output the word written using Peter Pan and Wendy frames on 5 lines. </p>
