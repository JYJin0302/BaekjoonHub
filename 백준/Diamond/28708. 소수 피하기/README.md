### 문제 설명

<p>$N$개의 양의 정수 $A_1, \cdots, A_N$이 주어집니다. 당신의 목적은 모든 $1 \le i < j \le N$에 대해서 $A_i + A_j$가 소수가 아니도록 만드는 것입니다.</p>

<p>이를 위해 당신은 다음 조작을 정확히 $1$번 할 수 있습니다.</p>

<ul>
	<li>$1$ 이상 $N$ 이하의 서로 다른 $K$개의 정수 $i_1, i_2, \cdots, i_K$를 고릅니다. $A_{i_1}, A_{i_2}, \cdots, A_{i_K}$에 각각 $1$을 더합니다. $(0 \le K \le N)$</li>
</ul>

<p>모든 $1 \le i < j \le N$에 대해서 $A_i + A_j$가 소수가 아니도록 하는 조작에서 $K$의 최솟값을 출력하세요.</p>

### 입력 

 <p>첫 줄에 수의 개수 $N$이 주어집니다. $(2 \le N \le 200)$</p>

<p>둘째 줄에 $A_1, \cdots, A_N$이 공백으로 구분되어 주어집니다. $(1 \le A_i \le 1\,000\,000)$</p>

### 출력 

 <p>모든 $1 \le i < j \le N$에 대해서 $A_i + A_j$가 소수가 아니도록 하는 조작의 $K$의 최솟값을 출력하세요.</p>

<p>$K \ne 0$인 경우, 둘째 줄에 고른 $i_1, i_2, \cdots, i_K$를 공백으로 구분하여 출력하세요. 정답이 여럿인 경우 아무거나 출력해도 좋습니다.</p>
