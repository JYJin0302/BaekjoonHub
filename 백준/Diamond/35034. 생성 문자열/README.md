### 문제 설명

<p>알파벳 소문자와 대문자로 구성된 $N(\leq 26)$개의 문자열 $S_1,S_2,\dots ,S_N$이 주어진다. 각 문자열 $S_i$는 $1$번부터 $N$번까지의 번호가 매겨져 있으며, 알파벳 대문자 ’A’는 $S_1$, ’B’는 $S_2$, $\dots$, $k$번째 알파벳 대문자는 $S_k$에 대응된다.</p>

<p>각 문자열 $S_i$를 바탕으로 문자열 $T_i$는 다음 규칙을 $S_i$의 첫 번째 문자부터 마지막 문자까지 순서대로 적용하여 생성된다.</p>

<ul>
<li>소문자인 경우: 해당 문자를 그대로 $T_i$에 추가한다.</li>
<li>대문자인 경우: 해당 대문자가 $k$번째 알파벳 대문자라면, $T_i$에 문자열 $T_k$를 추가한다.</li>
</ul>

<p>이 때 생성된 문자열 내부에 다시 대문자가 포함되어 있다면 동일한 규칙을 적용하여 문자열을 다시 생성한다. 이 과정에서 $T_i$의 길이는 <strong>무한히 증가</strong>할 수 있다.</p>

<p>예를 들어 $N=2$이고 $S_1=$ ”goodB”이고 $S_2=$ ”byeAbyeB”인 경우를 고려하자.</p>

<ul>
<li>$S_1$의 ’B’는 $T_2$로 대체되므로 $T_1$ = ”good” + $T_2$이다.</li>
<li>$S_2$의 ’A’는 $T_1$으로, ’B’는 $T_2$로 대체되므로 $T_2$ = ”bye” + $T_1$ + ”bye” + $T_2$이다.</li>
<li>이를 결합하면 $T_1$은 goodbyegoodbyeg..., $T_2$는 byegoodbyegoodb...와 같이 무한히 긴 문자열이 생성된다.</li>
</ul>

<p>$Q$개의 순서쌍 $(x_j,L_j,R_j)$이 주어진다. 각 순서쌍에 대하여 $T_{x_j}$의 $L_j$번째 문자부터 $R_j$번째 문자까지의 부분 문자열을 구하는 프로그램을 작성하라.</p>

### 입력 

 <p>첫 번째 줄에 문자열의 개수 $N$와 쿼리의 개수 $Q$가 주어진다.</p>

<p>이어지는 $N$개의 줄 중 $i$번째 줄에는 문자열 $S_i$가 주어진다.</p>

<p>이어지는 $Q$개의 줄 중 $j$번째 줄에는 각 쿼리를 나타내는 세 정수 $x_j$, $L_j$, $R_j$이 공백으로 구분되어 주어진다.</p>

### 출력 

 <p>$Q$개의 줄에 걸쳐 답을 출력한다. 이 중 $j$번째 줄에는 $T_{x_j}$의 $L_j$번째 문자부터 $R_j$번째 문자까지, 총 $R_j-L_j+1$개의 문자를 출력한다.</p>
