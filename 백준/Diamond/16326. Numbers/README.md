### 문제 설명

<p>A palindrome is an integer which reads the same backward as forward. For example, numbers 142241 and 102201 are palindromes, but 1023401 and 10510 — no. You want to represent a number n as the sum of two palindromes. Find the number of ways to do it.</p>

### 입력 

 <p>There is only one line containing the integer n (1 ≤ n ≤ 10<sup>18</sup>).</p>

### 출력 

 <p>Output one number — the number of ways to represent the number n as the sum of two palindromes.</p>
