### 문제 설명

<p>루나와 리나는 동전 뒤집기 게임을 하려고 한다.</p>

<p>동전 뒤집기 게임은 일렬로 놓인 $N$개의 동전으로 진행한다. 각 동전은 앞면 또는 뒷면이 위를 향하도록 놓여 있다.</p>

<p>게임은 루나부터 시작하여 두 플레이어가 번갈아 플레이한다. 자신의 턴에는 앞면인 동전 하나를 고른 뒤, 해당 동전이 구간의 오른쪽 끝점이 되도록 구간을 선택하여 동전들을 모두 뒤집는다. 이때 자신의 턴에 더 이상 시행할 수 없는 플레이어가 패배한다.</p>

<p>즉, 자신의 턴에 앞면인 $i$번째 동전을 고르고, $1\leq j\leq i$ 를 만족하는 j를 골라 $j\leq k\leq i$ 를 만족하는 모든 $k$번째 동전을 뒤집는다.</p>

<p>루나와 리나는 게임의 흥미를 위해 $N$개의 동전 중 특정 구간에 속하는 동전만을 사용하여 게임을 진행하려고 한다. 즉, $\frac{N(N+1)}{2}$ 개의 게임판 중 하나를 선택하여 게임을 진행한다.</p>

<p>리나는 자신이 불리한 것 같아 마음의 준비를 하려고 한다. 리나가 몇 개의 게임판에서 이길 수 있는지 구해보자.</p>

### 입력 

 <p>첫 번째 줄에 동전의 개수 $N$이 주어진다.</p>

<p>두 번째 줄에 동전들의 상태를 나타내는 길이 $N$의 문자열 $S$가 주어진다. $S$는 <code>H</code>, <code>T</code>로 이루어져 있으며, 이는 각각 $i$번째 동전이 앞면, 뒷면임을 나타낸다.</p>

### 출력 

 <p>리나가 이길 수 있는 서로 다른 게임판의 개수를 출력한다.</p>

<p>즉, $1\leq i\leq j\leq N$ 이며, 구간 $[i,j]$ 에 속한 동전만을 사용하여 게임을 진행하였을 때 리나가 게임을 승리하는 서로 다른 $(i,j)$ 쌍의 개수를 출력한다.</p>
