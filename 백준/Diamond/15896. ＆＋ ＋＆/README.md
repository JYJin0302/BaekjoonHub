### 문제 설명

<p>길이 N의 자연수 수열 2개 A<sub>1</sub>, A<sub>2</sub>, ..., A<sub>N</sub>과 B<sub>1</sub>, B<sub>2</sub>, ..., B<sub>N</sub>이 주어진다. 다음 2가지 값을 구하여라.</p>

<ul>
	<li>모든 (A<sub>i</sub> & B<sub>j</sub>)의 합을 1999로 나눈 나머지</li>
	<li>모든 (A<sub>i</sub> + B<sub>j</sub>)의 bitwise and 연산 값</li>
</ul>

<p>여기서 &는 bitwise and 연산을 의미한다. bitwise and 연산의 정의는 하단의 참고 사항에 있다.</p>

### 입력 

 <p>첫 번째 줄에 수열의 길이를 나타내는 자연수 N(1 ≤ N ≤ 10<sup>6</sup>)이 주어진다. 두 번째 줄에 수열 A를 나타내는 수 N개가 공백으로 구분되어 주어지고, 세 번째 줄에 수열 B를 나타내는 수 N개가 공백으로 구분되어 주어진다. A, B 수열의 모든 수는 1 이상 2<sup>28</sup> 이하의 자연수이다.</p>

### 출력 

 <p>첫 번째 줄에 위에서 언급한 2가지 값을 공백으로 구분하여 순서대로 출력한다.</p>
