### 문제 설명

<blockquote>
<p>"숨이 막힐 것 같이 차가웠던 공기 속에..."</p>
</blockquote>

<p>경기과학고의 본관은 $N$개의 교실을 $N-1$개의 복도가 연결한 트리 구조이다. 교실 $U_i$와 교실 $V_i$ 사이에는 거리 $W_i\ \text{m}$인 <strong>복도</strong>가 존재한다. $(1 \leq i \leq N-1)$ 원래대로라면 모든 교실의 <strong>난방 기구</strong>가 작동하는 것이 당연하지만, 경기과학고는 일부 교실만 <strong>난방 기구</strong>가 작동한다! (이거 진짜예요!!) $A_i$가 $0$이면 $i$번 교실의 <strong>난방 기구</strong>가 작동하지 않고, $1$이면 $i$번 교실의 <strong>난방 기구</strong>가 작동한다. $(1 \leq i \leq N)$ <strong>난방 기구가 작동하는 교실은 2개 이상 존재한다.</strong></p>

<p>당신은 <strong>난방 기구</strong>가 존재하는 교실에서 시작하여 다른 <strong>난방 기구</strong>가 존재하는 교실까지 가려고 한다. 당신은 초기에 온도가 $T$이고. 당신의 온도는 $1$초에 $1$씩 감소한다. 당신의 속도는 $1\ \text{m/s}$이고, 이동한 거리만큼 온도가 내려간다고 생각해도 된다. 온도가 음수가 되면 당신은 <strong>얼어붙어서</strong> 사망하게 된다. <strong>난방 기구</strong>가 있는 교실에 도달하면 온도가 다시 $T$가 된다. <strong>온도가 정확히 $0$인 시점에 난방 기구가 있는 교실에 도달하는 것도 허용된다.</strong></p>

<p>당신은 다음과 같은 질문에 $Q$번 답해야 한다. $i(1\leq i\leq Q)$번째 질문은 다음과 같다: 교실 $X_i$부터 교실 $Y_i$까지 <strong>얼어붙지 않고</strong> 도달할 수 있는가? <strong>교실 $X_i$와 $Y_i$는 모두 난방 기구가 작동하는 교실 중 하나이다.</strong></p>

### 입력 

 <p>첫 번째 줄에 경기과학고 본관의 교실 개수 $N$과 시작 온도 $T$가 공백으로 구분되어 주어진다.</p>

<p>두 번째 줄에 $N$개의 수 $A_i (1 \leq i \leq N)$이 공백으로 구분되어 주어진다. $A_i$는 $0$ 또는 $1$이다.</p>

<p>이후 $N-1$개의 줄에 걸쳐 그중 $i (1 \leq i \leq N-1)$번째 줄에 복도에 대한 정보 $U_i, V_i, W_i$가 공백으로 구분되어 주어진다.</p>

<p>다음 줄에 답해야 하는 질문의 개수 $Q$가 주어진다.</p>

<p>이후 $Q$개의 줄에 걸쳐 그중 $i (1 \leq i  \leq Q)$번째 줄에 $i$번째 질문에 대한 정보 $X_i, Y_i$가 공백으로 구분되어 주어진다.</p>

### 출력 

 <p>$Q$개의 줄을 출력한다.</p>

<p>$i (1 \leq i \leq Q)$번째 줄에는 $i$번째 질문의 답이 "가능하다" 이면 $1$을 출력하고, "불가능하다"이면 $0$을 출력한다.</p>
