### 문제 설명

<p><strong>혈귀 무리가 나란히 달리는 두 열차를 습격했다!</strong></p>

<p>혈귀 무리가 습격한 두 열차의 정보는 다음과 같다.</p>

<ul>
<li>두 열차는 각각 1번부터 $N$번까지 $N$개의 칸이 차례로 연결되어 있고, 같은 속도로 달리고 있다.</li>
<li>각 열차에서 $i (1 \le i \le N - 1)$번 칸은 $i + 1$번 칸과 서로 인접하다.</li>
<li>첫 번째 열차의 $i (1 \le i \le N)$번 칸은 두 번째 열차의 $i$번 칸과 서로 인접하다.</li>
<li>첫 번째 열차의 $i (1 \le i \le N)$번 칸에는 $a_i$명의 승객이 타고 있고, 두 번째 열차의 $i (1 \le i \le N)$번 칸에는 $b_i$명의 승객이 타고 있다.</li>
</ul>

<p>혈귀는 한 객차에 너무 많은 사람이 몰려 있으면 공격하기 어렵다. 반대로, 사람이 너무 적으면 습격할 가치가 없다. 따라서 혈귀는 살아있는 승객 수가 $lo$ 이상 $hi$ 이하인 모든 칸에 습격한다. 혈귀 무리는 총 $M$번 습격해온다. 매 습격마다 혈귀가 습격한 칸 중 살아있는 승객이 있는 칸에서는 <strong>승객이 1명씩 희생된다.</strong></p>

<p>열차에 타고 있던 피돌이는 혈귀 무리가 습격할 때마다 벽력일섬으로 혈귀를 해치우려고 한다. 벽력일섬은 인접한 칸에 습격한 혈귀들끼리 연결된 거대한 무리를 한번에 소탕할 수 있는 강력한 기술이다. 즉, 습격을 받은 칸 A에서 습격을 받은 인접한 칸으로만 이동하여 칸 B까지 이동할 수 있다면, 칸 A와 칸 B에 습격한 혈귀는 벽력일섬으로 한번에 소탕할 수 있다. 매 습격마다 피돌이는 최소 몇 번의 벽력일섬을 써야 모든 혈귀를 해치울 수 있을까?</p>

### 입력 

 <p>첫째 줄에 열차의 길이 $N$이 주어진다. $(1 \le N \le 300\,000)$</p>

<p>둘째 줄에 첫 번째 열차에 타고 있는 승객 수의 정보 $a_1$, $a_2$, $\cdots$, $a_N$이 공백으로 구분되어 주어진다. $(0 \leq a_i \leq 300\,000)$</p>

<p>셋째 줄에 두 번째 열차에 타고 있는 승객 수의 정보 $b_1$, $b_2$, $\cdots$, $b_N$이 공백으로 구분되어 주어진다. $(0 \leq b_i \leq 300\,000)$</p>

<p>넷째 줄에 습격의 횟수 $M$이 주어진다. $(1 \le M \le 300\,000)$</p>

<p>그 다음 줄부터 $M$개의 줄에 걸쳐 각 습격의 정보 $lo$, $hi$가 공백으로 구분되어 주어진다. 습격의 정보는 시간 순서대로 주어진다. $(0 \le lo \le hi \le 300\,000)$</p>

### 출력 

 <p>$M$개의 줄에 걸쳐 매 습격마다 피돌이가 써야 하는 벽력일섬의 최소 횟수를 출력한다.</p>
