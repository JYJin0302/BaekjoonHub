### 문제 설명

<p>양의 정수 $N$이 주어질 때, 아래 조건을 만족하는 $1$부터 $N$까지의 서로 다른 정수로 이루어진 길이 $N$의 순열 $P={P_1,P_2,\cdots,P_N}$을 만들어 보자.</p>

<ul>
	<li>모든 $1\le i, j \le N$에 대해 $P_i\oplus P_{N-i+1} = P_j\oplus P_{N-j+1}$</li>
</ul>

### 입력 

 <p>첫째 줄에 양의 정수 $N$이 주어진다. $(1 \le N \le 500\,000)$</p>

### 출력 

 <p>조건을 만족하는 순열이 존재하면 $P_1, P_2, \cdots, P_N$을 공백으로 구분하여 한 줄에 출력한다. 가능한 순열이 여러 개라면 아무거나 하나를 출력해도 된다.</p>

<p>조건을 만족하는 순열이 없으면 <code><span style="color:#e74c3c;">-1</span></code>을 출력한다.</p>
